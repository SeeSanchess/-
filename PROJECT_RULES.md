# Правила проекта

## Технологии

Использовать:

- HTML5
- CSS3
- JavaScript (Vanilla)

Не использовать:

- React
- Vue
- Angular
- jQuery (без необходимости)
- Другие фреймворки

## HTML

Использовать семантические HTML-теги:
- `<header>` для шапки сайта
- `<nav>` для навигации
- `<main>` для основного контента
- `<section>` для разделов
- `<article>` для самостоятельного контента
- `<aside>` для боковых панелей
- `<footer>` для подвала

## CSS

- Не использовать inline-стили без необходимости
- Использовать CSS-классы с осмысленными именами
- Следовать методологии БЭМ (Блок-Элемент-Модификатор)
- Использовать современные CSS-функции (Flexbox, Grid)
- Соблюдать порядок объявления свойств:
  1. Позиционирование
  2. Блочная модель
  3. Типографика
  4. Визуальное оформление
  5. Анимации и трансформации

## JavaScript

- Использовать современный синтаксис ES6+
- Соблюдать правила чистого кода
- Комментировать сложную логику
- Обрабатывать ошибки

## Дизайн

- Сайт должен быть адаптивным (mobile-first подход)
- Поддерживать основные разрешения:
  - Мобильные: 320px - 767px
  - Планшеты: 768px - 1023px
  - Десктопы: 1024px+
- Использовать систему цветов проекта
- Соблюдать типографическую иерархию

## Производительность

- Оптимизировать изображения
- Минимизировать CSS и JavaScript
- Использовать ленивую загрузку для изображений
- Кэшировать статические ресурсы

## Доступность (Accessibility)

- Использовать ARIA-атрибуты при необходимости
- Обеспечить навигацию с клавиатуры
- Поддерживать достаточный контраст текста
- Добавлять альтернативные тексты для изображений

## Код

- Не переписывать существующий код без необходимости
- Соблюдать единый стиль кодирования
- Использовать осмысленные имена переменных и функций
- Комментировать сложные участки кода
- Делить код на модули при необходимости

## Git

- Использовать осмысленные сообщения коммитов
- Создавать отдельные ветки для новых функций
- Регулярно делать коммиты
- Проверять код перед коммитом

## Тестирование

- Проверять кроссбраузерную совместимость:
  - Chrome (последняя версия)
  - Firefox (последняя версия)
  - Safari (последняя версия)
  - Edge (последняя версия)
- Тестировать на реальных устройствах
- Проверять адаптивность

## Документация

- Обновлять документацию при изменении кода
- Документировать публичные API
- Создавать README для новых компонентов

## Безопасность

- Валидировать пользовательский ввод
- Экранировать HTML-контент
- Использовать HTTPS

## Сборка и развертывание

- Автоматизировать сборку при необходимости
- Использовать минификацию для продакшена
- Настраивать кэширование
