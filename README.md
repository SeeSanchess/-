# Шаблон сайта "Бирюса - бытовая техника"

Сайт компании "Бирюса", специализирующейся на бытовой технике.

## Описание проекта

Одностраничный сайт для демонстрации продукции компании "Бирюса". Включает:
- Шапку сайта с логотипом и навигацией
- Слайдер с холодильниками
- Каталог товаров с карточками
- Боковую панель с преимуществами
- Подвал с контактной информацией

## Особенности реализации

### HTML
- Используются семантические HTML5 теги
- Чистая структура без лишних оберток
- Поддержка accessibility (ARIA-атрибуты)

### CSS
- Адаптивный дизайн (mobile-first)
- Flexbox для раскладки
- CSS Grid для сложных макетов
- Современные CSS-функции

### JavaScript
- Нативный JavaScript (без фреймворков)
- Слайдер с автоматическим переключением
- Интерактивные элементы

## Установка и запуск

1. Клонируйте репозиторий (если используете Git)
2. Откройте файл `index.html` в любом современном браузере

Для разработки:
1. Используйте редактор кода с поддержкой HTML/CSS/JavaScript
2. Откройте проект в VS Code, WebStorm или другом редакторе
3. Для live-reload можно использовать расширения браузера или серверы разработки

## Требования к окружению

- Современный браузер (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
- Редактор кода для разработки
- Git (опционально, для контроля версий)
